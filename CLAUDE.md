# alfea.io marketing site — standing rules

This branch (`marketing-site`) holds the consolidated alfea.io site: one
homepage linking to three services — Reactivate Leads (Kai), Website
Creation, and Walkthrough Videos (Julaide, a separate unchanged product
at julaide.io). It replaces three previously separate Netlify sites
(alfea.io, reactivate.alfea.io, web-creation.alfea.io).

This branch is deliberately an orphan branch with no shared history with
this repo's other branches, which hold an unrelated project (Alfea's
client-prospecting pipeline). Don't merge the two.

See `README.md` in this branch for structure, the design system, and the
"what not to touch" note about `web-creation.alfea.io` also hosting
unrelated per-client preview sites.
